Notes
  1. The OR node = IGN or charge Pin‑B (either diode pulls it high). It is the OR'd‑wakeup fed to the CM3.
  2. Hot: gate sits ~10V (the 1k/10k divider) → Q1 fully on. Cold: the 10k pulls the gate to 0 → off.
  3. D3 clamps the drain to 15V on release — 3V over the 12V rail, so the coil collapses fast = quick, clean contactor drop‑out. cathode→drain, anode→GND.
  4. Coil‑hi = Perm B+ via F‑Coil; the contactor is open in sleep, so the coil only draws in drive/charge.
  5. Board runs off Perm B+ (pre‑contactor). Reverse‑poly front‑end optional — not shown.
